Design Tokens & Typography System

A small CSS system built with custom properties (variables) for colour, type, spacing and more.

1. Colour Tokens

Colours are defined once in :root and reused everywhere with var(--token-name).

  • --color-primary
  • --color-secondary
  • --color-accent
  • --color-success
  • --color-danger
  • --color-text
  • --color-text-muted
  • --color-surface
