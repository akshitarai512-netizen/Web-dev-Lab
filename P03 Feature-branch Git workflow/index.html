Feature-Branch Git Workflow Guide

1. Repository Setup

  1. Navigate to folder: Open the terminal and change directories to the target folder.
    cd "P03 Feature-branch Git workflow"
  2. Initialize Git: Create a new Git repository and set the main branch name.
    git init
    git branch -M main
  3. Check Status: Verify untracked files and working tree state.
    git status
  4. Stage Files: Track all project files.
    git add .
  5. Initial Commit: Save the initial baseline state of the project.
    git commit -m "Initial commit"

2. Feature Development

  1. Create Branch: Make a new branch named feature.
    git branch feature
  2. Switch Branch: Move from main into the feature branch.
    git switch feature
  3. Make Changes: Modify project files on the feature branch.
    echo "<p>Feature branch update</p>" >> index.html
  4. Commit Changes: Stage and save the feature update.
    git add index.html
    git commit -m "Update index.html on feature branch"

3. Merging Changes

  1. Return to Main: Switch back to the main branch before merging.
    git switch main
  2. Merge Branch: Combine changes from feature into main.
    git merge feature
  3. Verify Status: Confirm that the merge completed and the working tree is clean.
    git status
