Quick Rule

  • Flexbox: one direction (row or column)
  • Grid: rows and columns together
  • Best: use both in one page

Which one should I use?

Use Flexbox to align items along a single line. Use Grid to place items in rows and columns. A real layout usually needs both.

Flexbox

Navigation Bar

Links sit in a single row and need equal spacing and vertical centring.

Grid

Page Layout

Header, sidebar, content and footer need rows and columns together.
