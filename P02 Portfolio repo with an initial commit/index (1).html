P2: Portfolio repo with an initial commit

Steps to Make the Initial Commit

  1. Create the project folder and go inside it 
    mkdir portfolio
cd portfolio
  2. Create the files 
    touch index.html style.css
  3. Turn the folder into a Git repository 
    git init
  4. Check the status (files are untracked) 
    git status
  5. Stage the files 
    git add .
  6. Check the status again (files are staged) 
    git status
  7. Make the initial commit 
    git commit -m "Initial commit"
  8. Check the status (working tree clean) 
    git status
  9. View the commit history 
    git log --oneline

Git Commands Practised

  • git init - Create a new Git repository
  • git status - Show the state of files
  • git add - Stage files for a commit
  • git commit - Save a snapshot of the staged files
  • git log - Show the commit history

Created using Terminal and Git.
