My First Project

This project was created using Terminal.

Steps to Create a Project in Terminal

  1. Check where you are 
    pwd

    pwd - Present working directory

  2. Go to the Documents folder 
    cd ~/Documents

    cd - Change directory

  3. See what is inside 
    ls

    ls - List files and folders

  4. Create the project folder 
    mkdir p1-project-folder

    mkdir - Create a folder

  5. Move into the project folder 
    cd p1-project-folder

    cd - Change directory

  6. Confirm your location 
    pwd

    The path should end with /p1-project-folder

  7. Create the HTML file 
    touch index.html

    touch - Create files

  8. Check the file was created 
    ls

    index.html should now appear in the list

  9. Open the page in the browser 
    open index.html

    open - Open a file (on Windows use: start index.html)

Commands Practised

  • pwd - Present working directory
  • ls - List files and folders
  • mkdir - Create a folder
  • cd - Change directory
  • touch - Create files
