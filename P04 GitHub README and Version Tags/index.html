Feature-Branch Git Workflow Guide

Step-by-step workflow for initializing, branching, updating, and merging in Git.

1. Setup & Initial Commit

  1. cd "P03 Feature-branch Git workflow" - Change directory
  2. git init - Initialize Git repository
  3. git branch -M main - Rename default branch to main
  4. git status - Check repository status
  5. git add . - Stage all files
  6. git commit -m "Initial commit" - Create initial commit

2. Feature Branching

  1. git branch feature - Create a feature branch
  2. git switch feature - Switch to feature branch
  3. echo "<p>Feature branch update</p>" >> index.html - Modify index.html
  4. git add index.html - Stage updated file
  5. git commit -m "Update index.html on feature branch" - Commit changes

3. Merging

  1. git switch main - Switch back to main branch
  2. git merge feature - Merge feature branch into main
  3. git status - Verify clean working tree
